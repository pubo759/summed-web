问题分级标准（参照《生产过程问题分级与岗位自互检标准》）

级别性质描述具体示例
A类（关键） 导致产品主要功能失效，易引发客户退货或投诉 产品规格与工艺标准不符（包装/套管针/埋植线型号错误；倒刺线/套管针不达标；标签信息错误）
一/二级包装功能失效（漏封、破损）
包装内缺件、无产品或含明显异物
B类（中度） 产品功能正常，但存在引起客户不满意的质量问题 一级包装内含轻微异物 · 套管针/海绵明显脏污划痕 · 包装来料外观印刷错误 · 产品物料外观不一致
C类（轻微） 客户难以察觉，或仅在生产中发现的微小偏差 二/三/四级包装外观不良（轻微脏污、划痕、封口贴松动）· 套管针轻微划痕

整改对策清单（对照岗位自互检标准）

每项措施在原有自互检要求基础上强化，分三层：自互检强化紧急纠正预防

① 漏贴品牌圆标签A类
自互检装铝箔袋岗位确认铝箔袋品牌与标签一致；装纸盒岗位确认纸盒品牌与标签一致
紧急在库成品全检补贴标签
纠正装袋/装盒工序增加"确认标签贴好"动作
预防控制标签领用数量（领用数=铝箔袋数/纸盒数）
② 空铝箔袋（未装纸塑袋即封口）A类
自互检装铝箔袋岗位确认铝箔袋内纸塑袋数量与工艺标准一致 → 铝箔袋封口岗位确认铝箔袋内纸塑袋数量与工艺标准一致
紧急在库铝箔袋100%手感检查，可疑空袋拆开确认
纠正增设"确认纸塑袋数量"动作
预防控制铝箔袋投料数（铝箔袋数=纸塑袋数×包装规格）
③ 纸盒无铝箔袋（双面胶松）A类
自互检装纸盒岗位确认纸盒内铝箔袋数量（附说明书）与工艺标准一致
紧急在库纸盒100%倒置检查，可疑盒拆开确认
纠正更换粘力更强的双面胶或增至2条；装盒后逐只倒置3秒检查；出库前纸盒重量抽检
预防双面胶来料每批做粘性测试（24h拉力≥2N）
④ 多放/少放铝箔袋A类
自互检装纸盒岗位确认纸盒内铝箔袋数量与工艺标准一致
紧急装盒工位张贴包装规格速查表
纠正装盒前核对型号→查表→确认包数；装盒后逐盒清点
预防每月装盒人员规格培训+考核
⑤ 漏放说明书B类
自互检装纸盒岗位确认纸盒内铝箔袋数量（附说明书）与工艺标准一致
紧急在库纸盒检查
纠正明确操作固定顺序：先放说明书→再放铝箔袋→封盒；封盒前目视确认
预防说明书领用台账（领用数=纸盒数），剩余回收
⑥ 套管针空针（未组装）A类
自互检组装OP确认按照工艺标准组装 → 组装桌长确认组装中间品按照工艺标准组装
紧急组装中间品100%检查
纠正明确组装、装袋工序自互检标准
预防不定期红牌测试强化自互检意识
⑦ 纸塑袋少针A类
自互检装袋OP确认装袋数量正确 → 装袋桌长确认纸塑袋内套管针数量正确 → 纸塑袋封口确认纸塑袋内套管针数量正确
纠正装袋后逐袋数支数，封口前两人确认
预防换型号时领班与桌长口头确认"此型号每袋X支"
⑧ 塞管脱落A类
自互检组装OP确认塞管无尺寸不良 → 装袋OP确认组装中间品外观正常（半钝针额外检查塞管的松紧）→ 装袋桌长半钝针额外检查塞管的松紧 → 送灭菌/装抽湿框/装铝箔袋各岗位均"半钝针额外检查塞管的松紧"
紧急组装中间品100%检查
纠正组装后轻拉塞管（~1-2N）确认不脱落；全流程轻拿轻放禁抛掷
预防不定期红牌测试强化自互检意识
⑨ 无海绵A类
自互检组装OP确认套管针/海绵/塞管/固定环无划痕、异物、尺寸不良 → 组装桌长确认套管针/海绵/塞管/固定环无质量问题
紧急组装中间品100%检查
纠正SOP固定顺序：放线→放海绵→确认海绵在位→放护套；组装后针座端目视/触感确认；装袋、纸塑袋封口工序确认
预防不定期红牌测试强化自互检意识

红牌抽查方案

抽查总则：每周至少1次不定期不预告抽查 · 每次覆盖≥2个岗位 · 不通知操作人员 · 随机抽样不挑批次

净化车间 · 组装OP岗位

确认套管针/海绵/塞管/固定环无划痕、异物、尺寸不良
防⑥⑧⑨ · 对照自互检要求第1条
确认按照工艺标准组装（针管内有线）
防⑥空针 · f=L看线尾外露 · f=W看塞管封住线尾 · 平滑线看海绵在位
确认切刺中间品规格与生产任务型号匹配
防⑥型号错误 · 对照自互检要求第3条
半钝针额外检查塞管/固定环的松紧
防⑧塞管脱落 · 参照自互检标准中多处"半钝针额外检查塞管的松紧"

净化车间 · 装袋OP / 装袋桌长 / 纸塑袋封口

确认纸塑袋质量与规格正常
防⑦ · 装袋OP自互检第1条
确认装袋数量正确
防⑦少针 · g=A/a/La=5支 · g=C/c/D/d=2支 · 装袋OP自互检第2条
确认组装中间品外观正常（半钝针额外检查塞管松紧）
防⑧ · 装袋OP自互检第3条
确认纸塑袋内无杂质、灰尘
装袋桌长自互检第1条
确认纸塑袋内套管针数量正确（半钝针额外检查塞管松紧）
防⑦⑧ · 装袋桌长自互检第2条 · 拆袋清点支数+轻拉塞管
确认纸塑袋（品牌）、套管针型号尺寸与标签一致
防①标签错误 · 装袋桌长自互检第3条
纸塑袋封口前确认数量正确（半钝针额外检查塞管松紧）
防⑦⑧ · 纸塑袋封口自互检第1条
确认纸塑袋按工艺标准封口、外观整洁无变形
纸塑袋封口自互检第2-3条

中包装车间 · 装铝箔袋 / 铝箔袋封口

确认纸塑袋外观整洁无变形、封口/袋内无杂质
装铝箔袋自互检第1条
确认铝箔袋型号规格与生产任务型号匹配
防①品牌错误 · 装铝箔袋自互检第2条
确认铝箔袋内纸塑袋数量与工艺标准一致
防②空袋 · 装铝箔袋自互检第3条 + 铝箔袋封口自互检第1条 · 手压确认内有扁平硬物
半钝针额外检查塞管的松紧
防⑧ · 装铝箔袋自互检第4条
确认铝箔袋封口正常、外观正常、封口数量与任务匹配
铝箔袋封口自互检第2-3条

中包装车间 · 装纸盒 / 装纸箱

确认纸盒外观整洁无变形
装纸盒自互检第1条
确认纸盒规格型号与生产任务型号匹配
防①④ · 装纸盒自互检第2条
确认纸盒内铝箔袋数量（附说明书）与工艺标准一致
防③④⑤ · 装纸盒自互检第3条 · 缇致小线4包 · C系列4-5包 · 沁络雅/纳美塑8包
纸盒倒置3秒检查铝箔袋不脱落
防③双面胶松 · 红牌抽查追加项
确认纸箱外观整洁无变形、规格型号匹配
防① · 装纸箱自互检第1-2条
确认纸箱内纸盒数量与工艺标准一致
装纸箱自互检第3条

植入缺陷红牌测试（验证各工序自互检有效性）

测试总则：每月至少1次不定期不预告 · 植入缺陷品做好隐蔽标记便于追溯 · 植入后不干预 · 观察各工序是否发现并拦截 · 记录发现工序+方式+时间
编号 植入缺陷 对应
不良		 植入位置 预期拦截工序（按流程顺序） 各工序检查要点 频次
RT-1 空针（套管针无埋植线） ⑥ 组装完成后混入正常中间品 ①组装OP自检 → ②组装桌长互检 → ③装袋OP → ④装袋桌长 → ⑤纸塑袋封口 f=L→线尾外露不可见；f=W→塞管在位但无线尾；平滑线→海绵在位但无线 每月1次
RT-2 无海绵 ⑨ 组装完成后混入 ①组装OP自检 → ②组装桌长互检 → ③装袋OP 针座端目视/触感确认海绵在位 每月1次
RT-3 塞管松动（可徒手拔出） ⑧ 组装完成后混入 ①组装OP → ②装袋OP → ③装袋桌长 → ④铝箔袋封口 轻拉塞管（~1-2N）即脱落 每月1次
RT-4 纸塑袋少放1支针 ⑦ 装袋后混入 ①装袋桌长 → ②纸塑袋封口 → ③装铝箔袋 拆袋清点支数不足（g=A/a/La=5支；g=C/c/D/d=2支） 每月1次
RT-5 空铝箔袋（无纸塑袋） ② 装铝箔袋后混入 ①铝箔袋封口 → ②装纸盒 手压铝箔袋无扁平硬物；有条件称重（空袋~3g vs 正常~15-25g） 每月1次
RT-6 纸盒无说明书 ⑤ 装纸盒后混入 ①装纸盒自检 → ②装纸箱 开盒目视确认说明书在位 每季度1次
RT-7 漏贴品牌圆标签 ① 装铝箔袋/装纸盒后混入 ①装纸盒 → ②装纸箱 目视品牌标签缺失 每季度1次
RT-1 空针红牌测试详细操作（示例）对应不良⑥
步骤1·准备取1支未装线的套管针（空针），做好隐蔽标记（如针座底部刻字），不影响外观目视
步骤2·植入在组装OP完成正常组装后，将空针混入下一批中间品中（不通知任何人）
步骤3·观察记录每个工序是否发现该缺陷：组装OP自检 → 组装桌长互检 → 装袋OP → 装袋桌长 → 纸塑袋封口
步骤4·拦截任一工序发现即拦截，记录发现工序、发现方式、拦截时间
步骤5·追溯未发现时追溯至最终环节（装纸盒/装纸箱），记录缺陷品流向
RT-3 塞管松动红牌测试详细操作对应不良⑧
步骤1·准备取1支已组装的半钝针（f=W），将塞管轻轻拔松（徒手可拔出但不掉落），做好隐蔽标记
步骤2·植入组装完成后混入正常中间品（不通知任何人）
步骤3·观察组装OP → 装袋OP → 装袋桌长 → 铝箔袋封口，各岗位"半钝针额外检查塞管的松紧"是否执行
步骤4·拦截轻拉塞管即脱落 = 发现拦截；未拉 = 未发现
RT-5 空铝箔袋红牌测试详细操作对应不良②
步骤1·准备取1只空铝箔袋（不装纸塑袋），封口后外观与正常品一致，做好隐蔽标记
步骤2·植入装铝箔袋后混入正常品中（不通知任何人）
步骤3·观察铝箔袋封口岗位是否手压确认内容物 → 装纸盒岗位是否开盒清点
步骤4·拦截手压无扁平硬物 = 发现拦截；未压/未发现 = 未拦截

红牌测试判定标准

判定条件处理
优秀 在第一道工序（组装OP自检或组装桌长互检）发现 自互检有效，记录表扬
合格 在第二道工序（装袋OP或装袋桌长）发现 下游拦截有效，上游需加强
警告 在第三道及以后工序（纸塑袋封口/装铝箔袋）发现 上游自互检失效，该工序段需整改
红牌 缺陷品未被发现，流出至装纸盒/装纸箱 停线 · 全线自互检复训 · 连续3次优秀恢复

红黄牌判定（日常抽查）

牌级判定条件处理
红牌 发现1件A类不良 停线 · 同批全检 · 8D报告48h · 全员复训 · 连续3次绿牌恢复
黄牌 发现1件B类不良或≥2件C类 标记记录 · 扩大抽检至20件 · 5工作日纠正报告 · 下次验证
绿牌 无不良 合格 · 正常流转
